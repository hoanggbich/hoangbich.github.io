# Logo

Save the official Masan Consumer logo in this folder as:

    masan-consumer-logo.png

(PNG with transparent background, ~40-60 px tall works best; SVG also works if you change the file name in index.html.)
You can download it from https://masanconsumer.com (right-click the logo in the site header -> Save image as).

Until the file exists, the header shows a text badge "Masan Consumer" instead.
